# Bogestv0 KARINA

Голосовой помощник для Windows. Откликается на имя **«Карина»**, понимает речь **без интернета**, отвечает голосом, открывает и закрывает ваши программы, меняет громкость, ищет в сети, выполняет ваши собственные команды. Оформление — в стиле MIXER / REMOTE / Unblock / VPN.

## Установка
1. Откройте **[Releases](../../releases/latest)** и скачайте:
   * `Bogestv0-KARINA-Setup-….exe` — **установщик** (рекомендуется): не требует прав администратора, добавляет ярлык в меню «Пуск», по желанию — автозапуск.
   * `Bogestv0-KARINA-Portable-….zip` — портативная версия: распаковать и запустить `Bogestv0-KARINA.exe`.
2. Windows может показать «Windows защитила ваш компьютер»: программа не подписана платным сертификатом. Нажмите **Подробнее → Выполнить в любом случае**. Контрольные суммы — в `SHA256SUMS.txt` рядом с файлами.
3. При первом запуске **один раз нужен интернет**: скачивается модель распознавания речи (~460 МБ). Дальше всё работает офлайн.
4. Нужен Microsoft Edge WebView2 (есть в Windows 11 и в обновлённой Windows 10).
5. Настройки и модель хранятся в `%APPDATA%\Bogestv0 KARINA` (при удалении программы не стираются).

## Запуск из исходников (для разработки)
1. Установите **Python 3.11 или 3.12** с python.org (поставьте галочку *Add Python to PATH*).
2. Запустите `run.bat`. Первый раз он сам поставит библиотеки (несколько минут).
3. При первом запуске **один раз нужен интернет**: скачивается модель распознавания речи (~460 МБ, потом работает офлайн). Она сохраняется в `data\models`.
4. Скажите: «Карина, открой блокнот».

## Как это работает
| Часть | Онлайн | Офлайн |
|---|---|---|
| Распознавание речи | Whisper на вашем компьютере | то же |
| Голос ответа | нейросетевой голос Microsoft (Светлана) | системный голос Windows (нужен русский: Параметры → Время и язык → Речь) |
| Понимание команд | список команд + (по желанию) Claude для свободных фраз | список команд |

Обращение: «Карина, …» или «…, Карина». После ответа несколько секунд можно говорить без имени. Если вас услышали, но не по имени — фраза игнорируется (видно в окне серым).

## Встроенные модели
Вкладка **Модели**: скачайте одну из моделей (≈3–17 ГБ), она хранится в `data\models\llm` (в установленной версии — `%APPDATA%\Bogestv0 KARINA\models\llm`). Движок llama.cpp входит в сборку; при запуске из исходников он скачивается сам при первом обращении к модели. Модель загружается в память при первом вопросе.

## Команды
Открыть/закрыть программу, переключиться на неё; громкость (громче, тише, «громкость пятьдесят», без звука); пауза/следующий трек; время и дата; скриншот; поиск; свернуть окна; напечатать текст; заблокировать; выключить/перезагрузить (с подтверждением «да»); «спи» / «проснись». Список — на вкладке **Команды**.

## Ваши программы
- **Bogestv0 MIXER / REMOTE / Unblock / VPN** уже знает: «миксер», «ремоут», «анблок», «впн». Запуск идёт через ярлык из меню «Пуск», который создаёт их установщик. Если стоит портативная версия — добавьте её на вкладке **Программы**.
- Любая программа из меню «Пуск» находится по названию.
- **Свои программы**: вкладка *Программы* → добавить путь и как её называть голосом.
- **Управление изнутри программы** (запись, сцены, подключение…): вкладка *Команды* → «Свои команды» — привязка фразы к сочетанию клавиш, запуску, ссылке или HTTP-запросу. Для сложной логики — плагин на Python: см. `plugins/_example.py`.

## Файлы
`data\config.json` — настройки · `plugins\` — плагины · `ui\` — окно · `karina\` — код · `tests\` — проверки.
`run-console.bat` — режим без окна для отладки (можно печатать команды).

## Обновление
При запуске (и по кнопке **Обновить** вверху) Карина смотрит последний релиз на GitHub. Если версия выше установленной, предлагает скачать и установить; установщик проверяется по `SHA256SUMS.txt`. Портативная версия и запуск из исходников открывают страницу релиза.

## Сборка и релиз
Сборка идёт на GitHub (Actions → *Build Windows*): тесты → PyInstaller → самопроверка exe → установщик Inno Setup → релиз.
Выпуск версии: поднимите `__version__` в `karina/__init__.py`, затем
```
git tag v1.0.0 && git push origin v1.0.0
```
Файлы появятся в Releases. Тег обязан совпадать с версией в коде.
