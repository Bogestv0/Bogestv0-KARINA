Кодер

Опишите задачу и приложите файлы (по желанию). Карина сама напишет код в отдельной папке проекта, запустит проверки, исправит ошибки и отдаст результат. Ваши файлы не меняются — она работает с копиями.

Без этой галочки Карина только пишет код и не проверяет его. Запуск — не песочница: программа выполняется с вашими правами. Разрешены только python, pytest и node, без сети, подпроцессов и удаления файлов (Карина проверяет код перед запуском). Нужен установленный Python или Node.js.

Встроенные команды

Начинайте с имени: «Карина, …». После ответа можно говорить без имени в течение нескольких секунд.

Свои команды

Привяжите фразу к действию: запуск программы, сочетание клавиш, ссылка, запрос к локальному API вашей программы.

Мозг Карины

Кто отвечает в чате и на свободные вопросы голосом. Команды управления компьютером («открой блокнот», «громкость…») всегда выполняются на этом компьютере.

В режиме Claude текст вашего вопроса, предыдущие реплики диалога и найденные в интернете страницы отправляются в Anthropic по вашему ключу и оплачиваются у вас. Файлы с компьютера не отправляются. Ключ хранится только на этом компьютере.

Встроенные модели

Работают прямо в Карине, бесплатно и без интернета. Модель скачивается один раз. Есть видеокарта — она ускорит ответы, нет — всё пойдёт на процессоре, но медленнее.
