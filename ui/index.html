Встроенные команды

Мозг Карины

Кто отвечает в чате и на свободные вопросы голосом. Команды управления компьютером («открой блокнот», «громкость…») всегда выполняются на этом компьютере.

В режиме Claude текст вашего вопроса, предыдущие реплики диалога и найденные в интернете страницы отправляются в Anthropic по вашему ключу и оплачиваются у вас. Файлы с компьютера не отправляются. Ключ хранится только на этом компьютере.

Бесплатные облачные модели

Быстрый «мозг» для слабых компьютеров. Зарегистрируйтесь у провайдера (карта обычно не нужна), нажмите «Получить бесплатный ключ», вставьте ключ и включите. Можно подключить несколько: у каждого свои бесплатные лимиты, и когда у одного они кончаются, Карина сразу переходит к следующему в очереди (порядок меняется стрелками). Затем выберите режим «Бесплатные облака» или «Авто» выше.

Текст вашего вопроса, предыдущие реплики диалога и найденные в интернете страницы уходят выбранному провайдеру по вашему ключу. Файлы с компьютера не отправляются. Ключи хранятся только на этом компьютере. Условия и лимиты бесплатных тарифов провайдеры меняют сами, а доступность из некоторых стран может быть ограничена.

Картинки

Карина рисует по просьбе: «нарисуй аниме-девушку с белыми волосами», «сделай обои с горами». Текстовая модель сама не рисует: она пишет подробное описание, а картинку создаёт генератор. По умолчанию это бесплатный сервис Pollinations (нужен интернет, ключ не нужен). Если он недоступен из вашей страны или нужна работа без интернета, подключите свой сервер Stable Diffusion (AUTOMATIC1111 / Forge, запуск с ключом --api) или любой сервис с OpenAI-совместимым API.

Встроенный аниме-генератор

Рисует прямо на вашем компьютере: без интернета (после загрузки), без водяного знака и с любой выбранной текстовой моделью. Скачивается один раз: движок stable-diffusion.cpp и аниме-модель. Нужна видеокарта от 6–8 ГБ; на процессоре картинка рисуется несколько минут.

Описание картинки уходит выбранному сервису: Pollinations — это сторонний сервер, «свой сервер» — ваш компьютер или сервис, который вы указали.

Встроенные модели

Работают прямо в Карине, бесплатно и без интернета. Модель скачивается один раз. Есть видеокарта — она ускорит ответы, нет — всё пойдёт на процессоре, но медленнее.

Вход через Google

Откроется браузер, вы выберете аккаунт Google, и Карина узнает ваше имя и почту. Пароль она не видит. Дату рождения и город Google не передаёт — их впишите ниже.

Настройка входа (один раз): Client ID
  1. Откройте console.cloud.google.com, создайте проект.
  2. «API и сервисы» → «Экран согласия OAuth»: тип «Внешний», добавьте себя в «Тестовые пользователи».
  3. «Учётные данные» → «Создать» → «Идентификатор клиента OAuth» → тип «Приложение для компьютера».
  4. Скопируйте Client ID (и Client secret) сюда.

Карина поздравит с днём рождения (вас и питомца), назовёт по имени, скажет погоду в вашем городе и будет знать клички: «как зовут мою собаку», «скажи погоду».

Обращение
Слух

Можно подключить до 4 микрофонов сразу. Каждый слушает сам по себе: если один расслышал плохо, помогают остальные, и Карина берёт лучший вариант фразы. Выключатель отключает микрофон, не убирая его из списка.

Голос

Работает на вашем компьютере, не роботизированный. Нужен пакет torch (один раз: pip install torch), поэтому работает при запуске из исходников (run.bat), а не в установленной exe-версии. Лицензия модели — для личного некоммерческого использования.

Микшер и VPN

«Карина, сделай тише музыку», «убавь звук в игре», «заглуши донаты», «включи сцену звонок», «включи впн», «выключи впн».

В микшере один раз включите «Настройки → Удалённый пульт». PIN и порт Карина обычно находит сама.

Нужно расширение Bogestv0 VPN версии 1.4.0 или новее: оно само подключается к Карине на этом компьютере.

Поиск в интернете (для чата)

Карина сама придумывает запросы, открывает и читает страницы, при нехватке данных ищет заново и в конце даёт ссылки на источники. Ключи не нужны. Тексты страниц считаются данными, а не командами.
